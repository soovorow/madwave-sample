# madwave.ru — source sample (Yii2)

Исходники интернет-магазина **madwave.ru** (экипировка для плавания), который я писал сам на PHP / **Yii2 Advanced**: каталог, корзина, оформление заказа, модули оплаты, интеграции (1С, рассылки, соцавторизация), мультиязычность RU/EU.

Это **образец кода для оценки** — выложен как снапшот рабочего проекта.

## ⚠️ Что сделано перед публикацией
Проект был приватным и содержал боевые данные. Перед выкладкой **вычищено**:
- все учётные данные и ключи (БД, SMTP, SFTP, платёжные merchant-ключи, OAuth/Google/reCAPTCHA) → заменены на `REDACTED_BEFORE_PUBLICATION`;
- дампы БД и MySQL-конфиги, service-account private key, OAuth client secret;
- персональные данные третьих лиц (контакты дилеров, phpinfo-дамп);
- пользовательские загрузки.

Поэтому проект **не запускается как есть** — смотреть его стоит как демонстрацию архитектуры и стиля кода, а не как разворачиваемое приложение.

## Стек
PHP 7, Yii2 Advanced (frontend / backend / common / console), MySQL, Composer, Codeception.
